# Adaptive-LQR-Control-for-Lane-Keeping-Systems-LKS-
Development of a Lateral Control System (Lane Keeping System) for Autonomous Vehicles using Adaptive LQR and Gain Scheduling. Implemented on SCANeR Studio and MATLAB/Simulink.
